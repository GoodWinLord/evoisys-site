# Evoisys — сайт, 3 варианта

Ветка gh-pages. Варианты:
- **v1.html** — быстрый одностраничник (вес ~3 КБ, цель LCP < 1 с). Кандидат на первый запуск.
- **v2.html** — основной: glassmorphism + свечение потоков воздуха, палитра C (циан/янтарь).
- **v3.html** — мобильный: mobile-first, липкая панель звонка/Telegram.

## До боевого запуска
1. Заменить телефон-заглушку +7 (999) 000-00-00 везде (текст, href="tel:", Schema.org).
2. Заменить t.me/evoisys на реальный ник.
3. Форма v2 — демо: подключить Telegram-бота (POST на webhook, токен не хранить в коде).
4. Вставить реальные фото в блок «Выполненные объекты» (сейчас заглушки, ничужие фото не используем).
5. DNS: evoisys.ru → GitHub Pages (A-записи 185.199.108–111.153) или Cloudflare Pages.
