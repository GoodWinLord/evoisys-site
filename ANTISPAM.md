# Защита формы заявок от ботов (evoisys.ru)

Включена 13.11.2026 после серии спам-заявок «напишите мне в вацап» с разных имён и номеров
(Валентина +79169175828, Вероника +79854648347, Валерия +79801882873).

## Слои защиты (сверху вниз)

| Слой | Где | Что делает |
|---|---|---|
| Honeypot-поле `honey` | страница + сервер | скрытое поле, человек его не заполнит; заполнено → тихий «ok», заявка не уходит |
| Ловушка времени 3 с | страница | отправка раньше 3 с от загрузки = просьба подождать |
| **Капча-задача (proof-of-work)** | страница + сервер | главный слой, см. ниже |
| Лимит частоты | сервер | больше 6 заявок с одного IP в час — тихо гасится (бот думает, что прошёл) |
| Отсев повторов | сервер | тот же телефон или тот же текст за сутки — тихо гасится |
| Turnstile | страница + сервер | готово, но спит: включится, когда в `leads.env` появится `TURNSTILE_SECRET` |

## Как работает капча-задача

1. При загрузке страницы форма берёт задачу: `GET https://api.evoisys.ru/api/challenge`
   → `{"nonce": "<32 hex>", "bits": 16, "ttl": 900}`.
2. В браузере ищется `counter`, при котором `sha256("<nonce>:<counter>")` начинается
   с 16 нулевых бит (≈ 65 тыс. хешей, 0.15–0.4 с, посетитель не замечает).
   Задача одноразовая, живёт 15 минут.
3. При отправке уходят поля `pow_nonce` и `pow_counter`. Сервер: задачи не знает,
   просрочена, уже использована, решена быстрее секунды или хеш не подходит → **403**,
   запись `{"blocked": "pow"}` в `/root/cf-site/leads.jsonl`.
4. Форм-бот, который рассылает одну заготовку на тысячи сайтов, такой схемы не знает
   и получает 403. Живой клиент ничего не замечает.

Почему без Cloudflare Turnstile: для Turnstile нужны sitekey+secret из аккаунта
Cloudflare (право Account → Turnstile → Edit). Токен на машине (`~/.cloudflare-token`)
имеет только Zone → DNS → Edit, поэтому API отдаёт `10000 Authentication error`.
Как только ключи появятся — Turnstile включается одной строкой и работает поверх задачи.

## Ручки (файл `/root/cf-site/leads.env` на VPS)

```
POW_OFF=1                # полностью выключить капчу-задачу
POW_BITS=18              # сложнее задача (больше нулевых бит)
TURNSTILE_SECRET=...     # включить Turnstile поверх задачи
```

После правки: `systemctl restart cf-site-leads.service`.
Проверка состояния: `curl -s https://api.evoisys.ru/api/health`
→ `{"ok":true,"tg":true,"bank":true,"pow":true,"turnstile":false}`.

## Проверки

```bash
# бот без задачи — должен получить 403
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://api.evoisys.ru/api/lead \
  -H 'Content-Type: application/json' \
  -d '{"name":"Бот","phone":"+79990000000","msg":"спам"}'

# задача выдаётся
curl -s https://api.evoisys.ru/api/challenge
```

Полные прогоны лежат на рабочей станции владельца:
`~/Агент/патчи/leads-turnstile/` — `run-tests-v3.py` (сервер, 10 кейсов),
`html-form-test.js` (настоящий код страницы в jsdom), `e2e-live.py` (боевой домен).

## Что видно в журнале заявок

`/root/cf-site/leads.jsonl` — обычные заявки, плюс отбитые:

```
{"blocked": "pow",   "why": "no-challenge", "name": "...", "phone": "...", "ip": "..."}
{"blocked": "rate",  "ip": "..."}
{"blocked": "dup",   "name": "...", "phone": "...", "msg": "..."}
{"blocked": "turnstile", "why": "bad:...", ...}
```

Такие записи — только след, в Telegram и в банк-память они не уходят.
